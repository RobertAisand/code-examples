# Примеры кода 1С

## 1c-extension
Расширение конфигурации для «Бухгалтерии предприятия»: колонка «Сумма реализации»
в списке документов «Счёт на оплату покупателю». Показывает сумму проведённых
документов «Реализация товаров и услуг», связанных со счётом.

**Как устроено:**
- доработка через `&После("ПриСозданииНаСервере")`, типовой код не правится;
- к запросу динамического списка добавляется поле и левое соединение;
- суммы по товарам и услугам объединяются (`ОБЪЕДИНИТЬ ВСЕ`) и группируются по счёту
  до соединения, чтобы счёт с несколькими реализациями не размножал строки;
- если в строке счёт не заполнен, берётся счёт из шапки реализации;
- если типовой запрос в другой версии изменится, доработка не применится,
  а список продолжит работать;
- колонка добавляется программно, потому что поле существует только в тексте
  запроса во время выполнения.

**Установка:** Конфигуратор → Конфигурация → Расширения конфигурации → Добавить →
загрузить из файлов, папка `1c-extension`.
