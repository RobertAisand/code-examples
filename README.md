# Примеры кода на 1С

Небольшие примеры по основным темам разработки на платформе 1С:Предприятие 8.
В каждой папке есть свой README с описанием.

| Папка | Что внутри |
|---|---|
| `1c-extension` | Расширение конфигурации |
| `queries` | Примеры запросов: остатки по складам, продажи по клиентам с классами, залежавшиеся товары |
| `http-service` | HTTP-сервис (получение остатков по артикулу) и клиентский вызов |
| `utils` | Общие функции: проверка ИНН, запись исключений в журнал регистрации |
| `external-processing` | Внешняя обработка для ЗУП 3.1 в формате файлов: пакетный запрос, срез последних, вывод через макет |

Весь код написан по стандартам разработки 1С.
