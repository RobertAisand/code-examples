# Внешняя обработка для ЗУП 3.1

Отчёт по действующим сотрудникам со статусом налогоплательщика
«Нерезидент, работающий по найму на основании патента» и данными
уведомления об авансовых платежах за текущий год.

Выгружено в формат файлов (иерархический), собирается обратно в .epf
командой платформы LoadExternalDataProcessorOrReportFromFiles.

## Что показано

- Пакетный запрос с временными таблицами и индексами.
- Статус физлица на дату через срез последних периодического регистра.
- Сравнение по предопределённому элементу справочника, а не по тексту.
- Левое соединение: сотрудник без уведомления остаётся в отчёте.
- Вывод через макет (области заголовка, шапки, строки, итога).

## Колонки

ФИО, действующая организация, номер уведомления, дата уведомления.
Уведомления за год, отличный от текущего, игнорируются.
