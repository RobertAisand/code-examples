# HTTP-сервис остатков (1С)

Простой REST-сервис на платформе 1С и клиент к нему.

| Файл | Назначение |
|---|---|
| `service_module.bsl` | Модуль HTTP-сервиса `ТоварыAPI`: `GET /api/v1/stock/{Артикул}` возвращает остаток в JSON |
| `client.bsl` | Функция `ОстатокПоАртикулу` для вызова сервиса из другой базы |

## Настройка сервиса
- HTTP-сервис `ТоварыAPI`, корневой URL `api`
- Шаблон `Остатки`, URL `/v1/stock/{Артикул}`, метод `GET`, обработчик `ОстаткиGET`
- База опубликована на веб-сервере, пользователю выдана роль с доступом к сервису

## Ответы
- `200`: `{"article": "ABC-001", "stock": 12}`
- `404`: `{"error": "Товар не найден"}`

## Проверка
`curl -u user:pass "http://localhost/<публикация>/hs/api/v1/stock/ABC-001"`

Для остатков используется регистр `ТоварыНаСкладах` (УТ 11.5), при другой конфигурации поправьте имя в запросе.
