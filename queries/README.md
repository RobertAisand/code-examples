# Примеры запросов 1С

Три функции в `Запросы.bsl` (УТ 11.5, платформа 8.3+):

| Функция | Что показывает |
|---|---|
| `ОстаткиТоваровПоСкладам` | Виртуальная таблица остатков с параметрами, группировка, `ИМЕЮЩИЕ` |
| `ПродажиПоКлиентамСКлассами` | Пакетный запрос, временная таблица, `ВЫБОР КОГДА`, `ИТОГИ` |
| `ЗалежавшиесяТовары` | Временная таблица с индексом, левое соединение и поиск отсутствующих записей |

Во всех запросах значения передаются параметрами, а отбор по регистрам идёт через параметры виртуальных таблиц.

## Как проверить
1. Скопировать нужную функцию в общий модуль или внешнюю обработку базы на УТ 11.5.
2. Вызвать функцию из консоли кода, например `ОстаткиТоваровПоСкладам(ТекущаяДата(), МассивСкладов)`.
3. Результат возвращается таблицей значений, а для второго примера деревом значений.

Если в вашей конфигурации другие имена реквизитов, поправьте их в тексте запроса.
