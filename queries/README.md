# Примеры запросов 1С

Три функции в `Запросы.bsl` (УТ 11.5, платформа 8.3+):

| Функция | Что показывает |
|---|---|
| `ОстаткиТоваровПоСкладам` | Виртуальная таблица остатков с параметрами, группировка, `ИМЕЮЩИЕ` |
| `ПродажиПоКлиентамСКлассами` | Пакетный запрос, временная таблица, `ВЫБОР КОГДА`, `ИТОГИ` по классам A, B, C |
| `ЗалежавшиесяТовары` | Временная таблица с индексом, левое соединение, поиск товаров без продаж |

Во всех запросах значения передаются параметрами запроса, а отбор по регистру идёт через параметры виртуальной таблицы.

## Параметры

- `ОстаткиТоваровПоСкладам(Дата, Склады)`: `Склады` обязателен, это массив ссылок на склады; пустой массив даёт пустой результат.
- Для функций с периодом передавайте конец дня (`КонецДня(Дата)`), иначе документы последнего дня не попадут в остатки.

## Как проверить

1. Скопировать функции в общий модуль или внешнюю обработку базы на УТ 11.5.
2. Вызвать функцию из консоли кода, например `ОстаткиТоваровПоСкладам(ТекущаяДата(), МассивСкладов)`.
3. Результат: таблица значений, для `ПродажиПоКлиентамСКлассами` дерево значений (первый уровень: класс, второй: клиенты).

Если в вашей конфигурации реквизиты называются иначе, поправьте их в тексте запроса.
