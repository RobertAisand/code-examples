# Утилиты 1С

Две небольшие функции общего назначения для общего модуля 1С.

## ИННКорректен

Проверяет ИНН юридического лица (10 цифр) и физического лица (12 цифр)
по контрольным разрядам, а также отсекает строки с нецифровыми символами.

    Если Не ИННКорректен(Контрагент.ИНН) Тогда
        Сообщить("ИНН указан неверно");
    КонецЕсли;

Пример корректного ИНН: 7707083893.

## ЗаписатьИсключение

Записывает ошибку в журнал регистрации вместе с подробным описанием исключения.

    Попытка
        ЗагрузитьДанные();
    Исключение
        ЗаписатьИсключение("Обмен.Загрузка", ИнформацияОбОшибке(), "Не удалось загрузить файл");
    КонецПопытки;

## Что здесь показано

- Экспортные функции с описанием параметров и возвращаемого значения.
- Вынос повторяющейся логики во вспомогательную функцию.
- Работа с журналом регистрации.
